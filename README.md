## FAQ

**1) Does private vpn for privacy keep activity logs?**  
It’s built around a **No-Logs policy** and a privacy-first stance.

**2) What happens if the VPN connection drops?**  
Enable the **Kill Switch**. It blocks traffic until the tunnel is back, preventing leaks.

**3) Will it slow down my internet?**  
Any VPN adds overhead, but this setup aims for **high speed** and a **stable connection**. Choose a nearby server for best results.

**4) Can I switch locations?**  
Yes. Use the **Global Servers** list to change exit regions as needed.
